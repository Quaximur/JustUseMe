```bash
cd MyGame
git remote remove origin
```

## 🎮 Features & Implementation

### **Core**
- **Modular Bootstrap**: Application startup built from independent modules.
- **Scene Management**: Structured scene loading and game flow.
- **Game Services**: Settings, audio, localization and other common game systems.

### **Architecture**
- **Dependency Injection**: Reflex-based composition and module registration.
- **Async & Reactive**: UniTask and R3 integrated into the project foundation.
- **UI**: DevKit.UI with Unity UI and UI Toolkit support.

### **Quality of Life**
- Assemblies segregation.
- Common game features implementation.
- Clean reusable code.
- Common helpers and extensions for everyday Unity development.
